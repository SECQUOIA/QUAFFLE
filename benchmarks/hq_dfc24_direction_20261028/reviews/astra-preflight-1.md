The architecture implements the intended transfer. The depthwise/pointwise convolutions use BatchNorm and ReLU; the ordinary U-Net skips remain, while the deepest DoubleConv is replaced without a bottleneck identity addition or attention/modulation path. The common interface pools to 4×4, projects to three channels and encodes tanh outputs directly as radians without multiplying by pi. The quantum arm uses the existing actual 16-qubit kernel, shared horizontal/vertical filters and 32 Z/X expectations, followed by full dense reconstruction. The MLP receives the same 48 encoded values and uses 48→64→32, SiLU and final tanh. The quantum core has eight parameters; the MLP core has 5,216. These are deliberately different function classes with identical common interfaces, not a claim of parameter-matched quantum superiority. This matches the architectural elements described in [HQ-UNet, section III-B](https://arxiv.org/html/2604.27206v1); the protocol appropriately distinguishes binary DFC24 adaptation from reproduction of the paper's LandCover.ai result.

The constructor isolates core RNG draws and preserves identical non-core weights and BatchNorm buffers across arms. CPU per-sample circuit checkpointing operates inside the core, leaving the surrounding model batch and BatchNorm semantics intact. Tests check independent PennyLane output/gradient parity, actual model gradients, geometry, no bypass, diagnostic semantics, and strict reconstruction including BatchNorm counters and running statistics. Existing circuit and legacy model source is unchanged by this change.
